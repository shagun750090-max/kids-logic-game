# 🌟 Kids Easy Logic Game (बच्चों का आसान लॉजिक गेम) 🎈

छोटे बच्चों (3 से 7 साल) के लिए बहुत ही सरल, आकर्षक और बुनियादी (Basic Level) लॉजिक गेम, जिसे **HTML5**, **CSS3** और **Vanilla JavaScript** से बनाया गया है।

अब इस गेम में **पूरे 30 मजेदार लेवल्स** हैं!

---

## 🎮 30 लेवल्स में क्या-क्या है? (30 Levels Overview)

1. **अलग पहचानो (Odd One Out)**:
   - Level 1: `[🐶, 🐶, 🐱, 🐶]` -> अलग बिल्ली (🐱)
   - Level 3: `[🍎, 🍎, 🍌, 🍎]` -> अलग फल केला (🍌)
   - Level 5: `[🚗, 🚗, ✈️, 🚗]` -> उड़ने वाला हवाई जहाज (✈️)
   - Level 8: `[🍦, 🍦, 🍕, 🍦]` -> अलग खाना पिज़्ज़ा (🍕)
   - Level 9: `[🐘, 🐘, 🐭, 🐘]` -> सबसे छोटा चूहा (🐭)
   - Level 10: `[🌸, 🌸, 🌸, 🦋]` -> उड़ने वाली तितली (🦋)
   - Level 11: `[🐟, 🐟, 🦁, 🐟]` -> जो पानी में नहीं रहता (🦁 शेर)
   - Level 14: `[🦜, 🦜, 🦜, 🐢]` -> पक्षियों में कछुआ (🐢)
   - Level 17: `[⛄, ⛄, 🔥, ⛄]` -> गरम आग (🔥)
   - Level 21: `[🍩, 🍩, 🥦, 🍩]` -> हरी सब्जी ब्रोकोली (🥦)
   - Level 24: `[😀, 😀, 😴, 😀]` -> सोने वाला चेहरा (😴)
   - Level 27: `[🎸, 🎸, ⚽, 🎸]` -> खेलने वाली गेंद (⚽)

2. **रंग और आकृतियाँ पहचानो (Color & Shape Match)**:
   - Level 2: लाल रंग (🔴)
   - Level 6: चमकता सितारा (⭐)
   - Level 13: पीला रंग (🟡)
   - Level 19: नीला रंग (🔵)

3. **आसान पैटर्न (Simple Patterns - What comes next?)**:
   - Level 4: `[🦁, 🐵, 🦁, ❓]` -> 🐵
   - Level 7: `[🔴, 🟢, 🔴, ❓]` -> 🟢
   - Level 12: `[1️⃣, 2️⃣, 3️⃣, ❓]` -> 4️⃣
   - Level 15: `[🍇, 🍓, 🍇, ❓]` -> 🍓
   - Level 18: `[☀️, 🌙, ☀️, ❓]` -> 🌙
   - Level 22: `[❤️, ⭐, ❤️, ❓]` -> ⭐
   - Level 26: `[🎈, 🎈, 🎁, 🎈, 🎈, ❓]` -> 🎁
   - Level 29: `[🟡, 🟣, 🟡, ❓]` -> 🟣

4. **तार्किक जोड़ियाँ और समझ (Logic & Associations)**:
   - Level 16: दूध कौन देती है? -> गाय (🐮)
   - Level 20: गाजर किसे पसंद है? -> खरगोश (🐰)
   - Level 23: पानी में क्या तैरता है? -> जहाज (🚢)
   - Level 25: कूदने वाला हरा मेंढक (🐸)
   - Level 28: मीठा शहद कौन बनाती है? -> मधुमक्खी (🐝)
   - Level 30: जंगल का राजा कौन है? -> शेर (🦁)

## ✨ बच्चों के लिए खास खूबियाँ (Kid-Friendly Features)

- 🗣️ **बोल कर सुनाने वाला बटन (🔊 Voice Support)**: बच्चे अगर पढ़ नहीं सकते, तो वे **"🔊 Bol kar sunao"** बटन दबा सकते हैं। ब्राउज़र हिंदी और अंग्रेजी में सवाल बोलकर समझाएगा।
- 🎶 **खुशनुमा आवाजें (Web Audio Sound)**: सही जवाब पर खूबसूरत घंटी (Ding! 🎵), और गलत पर हल्का सा मजेदार कंपन (Boop)।
- 🎊 **कन्फेटी सेलिब्रेशन (Confetti Sparkles)**: सही उत्तर देने पर स्क्रीन पर रंग-बिरंगे सितारे उड़ते हैं।
- 📊 **प्रोग्रेस बार (Progress Bar)**: ऊपर रंगीन प्रोग्रेस बार दिखाता है कि बच्चे ने कितने लेवल्स पूरे कर लिए हैं।
- ⭐ **स्टार्स स्कोर (Star Rewards)**: हर सही उत्तर पर सुनहरा सितारा मिलता है।
